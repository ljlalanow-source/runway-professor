# 나만의 교수 에이전트 · RUNWAY

배우고 싶은 과목을 매일 아침 5분짜리 글 강의로 가르쳐 주는 텔레그램 에이전트.
퀴즈를 풀어야 다음 날 다음 강의가 와서, 안 본 강의가 쌓이지 않는다.

## 시작하기

1. 이 폴더를 내려받아 VS Code로 연다.
2. Claude Code에 이렇게 말한다.
   ```
   교수-만들기.md 대로 내 교수 만들어 줘
   ```

## 준비물

- 휴대폰 (텔레그램)
- GitHub 계정
- 배우고 싶은 과목 1~3개와 "어디까지 가고 싶은지" 한 줄
