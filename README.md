# 나만의 교수 에이전트 템플릿 · RUNWAY

배우고 싶은 과목을 **매일 아침 5분짜리 글 강의와 퀴즈**로 가르쳐 주는 텔레그램 에이전트를 만든다.
**퀴즈를 풀어야 다음 날 다음 강의가 온다.** 안 본 강의가 쌓이지 않는다.

```
📣 마케팅 3강 · 포지셔닝: 마음속 자리 잡기

🤔 오늘의 질문
왜 같은 커피인데 어떤 브랜드는 '작업하러 가는 곳'이 됐을까요?

📖 개념 · 🪄 비유 · 🔍 실제로는 · 💼 내 일에는 · 📌 한 줄 요약

아래 퀴즈를 풀면 내일 4강이 와요 👇
[퀴즈 투표: 누르면 바로 정답과 해설]
```

- 텔레그램 **토픽 그룹** 하나에 과목마다 탭 (예: 📣 마케팅 · 🤖 AI · 💰 경제)
- 과목마다 진도가 따로. 사흘째 안 풀면 한 번만 살짝 알려 준다
- 틀린 문제는 3일 뒤, 7일 뒤 다시 나온다
- 궁금한 건 탭에 톡으로 남기면 다음 강의 첫머리에 답해 준다
- 과목 방식: **커리큘럼형**(기초부터) · **사례형**(실제 사례로) · **뉴스 연결형**(이번 주 뉴스를 이해하는 이론)

## 시작하기

1. 이 폴더를 내려받아 VS Code로 연다. (초록 **Code** 버튼 → **Download ZIP**)
2. Claude Code에 이렇게 말한다.
   ```
   이 템플릿으로 내 교수 만들어 줘
   ```
3. Claude가 한 단계씩 안내한다. 과목별 수준은 대화로 확인한다. 막히면 화면을 캡처해서 붙여 넣고 물어본다.

## 준비물

- 휴대폰 (텔레그램 설치)
- GitHub 계정 (매일 아침 자동으로 보내려면 필요)
- 배우고 싶은 과목 1~3개와 "어디까지 가고 싶은지" 한 줄

## 파일

| 파일 | 하는 일 |
|---|---|
| `CLAUDE.md` | 교수의 규칙표 (매일 아침 순서, 강의 모양, 퀴즈) |
| `SETUP.md` | Claude가 따라가는 설정 순서 |
| `config.json` | 교수 이름, 배우는 사람, 과목 설정 (설정하면서 생긴다) |
| `subjects/<과목>/` | 과목별 수준(`level.md`)과 목차(`curriculum.md`) (설정하면서 생긴다) |
| `check_answers.py` | 퀴즈 답을 읽어 오늘 강의를 보낼지 정한다 |
| `send.py` · `quiz.py` | 강의와 퀴즈를 과목 탭으로 보낸다 |
| `news.py` | 뉴스 연결형 과목의 최근 뉴스 모으기 |
| `progress_sync.py` | 진도표를 GitHub `claude/progress` 브랜치에 저장하고 불러온다 |
| `setup_topics.py` | 과목 탭 만들기 (처음 한 번) |
| `.env` | 텔레그램 토큰. **GitHub에 올라가지 않는다** |
